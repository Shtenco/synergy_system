## Promotion rule for source repositories

A source/legacy repository component can move into a canonical target only after:

1. exact source/version identification;
2. role uniqueness check;
3. dependency and authority analysis;
4. current tests/benchmark reproduction;
5. evidence package;
6. migration mapping (`source → target`);
7. canonical-target PR;
8. registry update.
