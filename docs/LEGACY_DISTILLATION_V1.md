## Economic regression constitution

A canonical financial engine must reject all of the following as standalone sources of external profit:

```text
own token appreciation
internal AMM mark
self-LP reallocation
flash-loan principal
internal transfer
new investor capital
QE asset creation without balanced counter-entry
synthetic yield without an identified external payer/settlement source
ROI computed from a zero or near-zero economic denominator
```

The legacy corpus is preserved as provenance and falsification evidence. New authority code is distilled from it rather than replacing the archive or silently inheriting its old assumptions.
