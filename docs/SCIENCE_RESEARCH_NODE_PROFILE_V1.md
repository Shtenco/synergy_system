# SCIENCE_RESEARCH_NODE profile v1

`SCIENCE_RESEARCH_NODE` composes four operational roles:

- SynergyNet P2P relay;
- SynergyNet content cache;
- AGI NEXUS compute;
- NEXUS Science Agent research service.

Allowed capabilities are exactly `CONTENT_CACHE`, `NEXUS_COMPUTE`, `P2P_RELAY`, and `SCIENCE_RESEARCH`.

The profile explicitly forbids `AUTOPILOT`, `BLOCKCHAIN`, `FINANCIAL_OS`, `METAPAY`, and `MIDAS` service kinds. It grants no financial, payment, accounting, or execution authority.
