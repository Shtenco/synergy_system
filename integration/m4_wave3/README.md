# M4 Wave 3 — Research / Intelligence / Compression Federation

Five additional repositories are integrated through locally reproducible capabilities:

```text
Relative Value ─────────→ MIDAS
Agentic AI Economy ─────→ NEXUS
DLP Solver ─────────────→ Science Agent
Cold Nuclear ───────────→ Science Agent
QR Compress ────────────→ Meta-OS
```

Authority rules:

- relative-value z-score is advisory evidence, never an order;
- agent economy state is simulation context and has no payment/accounting authority;
- DLP constraint measurements do not self-declare a cryptographic break;
- cold-nuclear graph/model checks do not self-declare an observed physical effect or causal mechanism;
- compression benchmark proves byte equality/temporal cutoff but cannot grant deployment authority.

Wave 3 deliberately excludes external-runtime-dependent candidates such as MT5/network-bound miners from this offline E2E gate.
